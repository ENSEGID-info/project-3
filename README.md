# projet du grp 3
Project of Team 3

Ce projet intitulé "Reconnaissance de strates dans la photogrammétrie d’affleurements" a été réalisé dans le cadre du cours de programmation.
Ce projet sur des outils informatiques en équipe est une mise en situation qui vise divers objectifs proactifs.
Notamment parcequ'il y a la mise en forme d'un esprit d'analyse, d'équipe, d'une certaine rigueur méthodique en somme.

This project, entitled "Strat Recognition in Photogrammetry field," is a project using computer tools.
It's provide a practical application with several proactive objectives.
In particular, analytical thinking, teamwork, and a certain methodical rigor.

Il y a trois sous groupes et une répartition organisé de tâches ciblées.

There are three parts in the team, and this is the best way for a better organization.
